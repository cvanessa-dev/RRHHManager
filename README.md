# 👥 Sistema de Recursos Humanos (RRHHManager)

> 🚧 **Proyecto en desarrollo** — todavía no está listo para usarse.

Sistema web para la gestión de Recursos Humanos, desarrollado en C# con ASP.NET Core MVC, Entity Framework y SQL Server.

## 📋 Tecnologías utilizadas

- C#
- ASP.NET Core MVC (.NET 8)
- Entity Framework Core
- SQL Server
- Visual Studio

## 🧩 Módulos planeados

- Empleados
- Departamentos
- Puestos
- Vacaciones
- Usuarios y Roles
- Constancias
- Cálculo de prestaciones
- Reportes
- Expedientes
- Incapacidades
- Permisos
- Historial
- Auditoria
